# Support

Visit [Homport support](https://homport.dev/support/) or email [support@homport.dev](mailto:support@homport.dev).

For general questions, start with [Getting started](docs/getting-started.md) and the [FAQ](docs/faq.md). The Microsoft Store release is being prepared; current availability is shown on [homport.dev](https://homport.dev/).

## Reporting a problem

Include the Homport version, Windows version, the action you were taking, what you expected, what happened, and any visible error code. Add short reproduction steps if possible.

Review screenshots and diagnostic reports before sharing them. Remove personal email addresses, private share links, local paths and account details. Never send API tokens, OAuth tokens, connector tokens, passwords, email verification codes or unredacted credential files.

GitHub issues are public. Use email for anything sensitive and follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not post credentials even in a private support email.
