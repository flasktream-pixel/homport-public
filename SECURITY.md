# Reporting a security concern

Please report suspected Homport vulnerabilities privately to [support@homport.dev](mailto:support@homport.dev), using a subject beginning with **Security report**. Do not publish exploit details in a GitHub issue before they can be assessed.

Include the affected Homport version, a description of the issue, its potential impact and reproduction steps using synthetic data. Do not send passwords, tokens, email verification codes, or another person's account details. If a secret was exposed, revoke or rotate it through the relevant provider.

Only test systems and accounts you own or have permission to test. Homport is independent of Cloudflare; issues in Cloudflare itself should be reported through Cloudflare's own security reporting process.

The first Microsoft Store release is being prepared. No supported-version schedule or response-time commitment has been published yet.
